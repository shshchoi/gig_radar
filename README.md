# 🎧 GIG RADAR

> **내 취향에 맞는 공연을 찾아주고, 티켓팅 날짜까지 챙겨주는 AI**

검색어를 알아야 결과를 주는 일반 검색과 달리, GIG RADAR는 **좋아하는 아티스트만 알려주면 비슷한 아티스트 공연까지 찾아주고**, 팬들이 가장 신경 쓰는 **티켓 오픈 일정을 D-day와 캘린더 알림으로** 챙겨줍니다.

## 💡 일반 검색과 무엇이 다른가요?

| | 일반 검색 (구글 등) | GIG RADAR |
|---|---|---|
| 찾는 방법 | 가수 이름·공연명을 알아야 함 | **취향만 말하면** 몰랐던 아티스트 공연까지 추천 |
| 결과 형태 | 여러 사이트를 직접 열어서 확인 | 날짜·장소·예매 정보를 **카드 하나로 정리** |
| 티켓팅 | 공지를 직접 찾아서 날짜 확인 | **선예매·일반예매 D-day** 자동 표시 |
| 일정 관리 | 캘린더에 직접 입력 | **버튼 한 번으로 캘린더 추가**, 티켓팅 30분 전 알림 |

## ✨ 주요 기능

### 💖 취향으로 찾기
- 좋아하는 아티스트(예: `잔나비, 실리카겔, 혁오`)와 원하는 분위기를 입력해요.
- AI가 **취향을 한 줄로 분석**하고 **비슷한 아티스트**를 골라 보여줘요.
- 좋아하는 아티스트와 비슷한 아티스트의 공연, 그리고 이들이 나오는 페스티벌을 찾아줘요.
- 카드마다 **"왜 이 공연이 나에게 맞는지"** 추천 이유가 붙어요.

### 🔍 공연 검색
- 가수 이름이나 키워드로 다가오는 공연을 찾아요.
- 지역(국내/해외/전체)과 종류(콘서트/페스티벌/뮤지컬·공연)로 걸러 볼 수 있어요.

### ⏰ 티켓팅 D-day
- 선예매와 일반예매 오픈 일시를 따로 보여줘요.
- 가장 가까운 티켓 오픈까지 남은 날을 배지로 표시해요. 3일 이하로 남으면 🔥 배지가 깜빡여요.
- 일주일 안에 티켓팅이 열리는 공연 수를 결과 맨 위에 알려줘요.

### 📅 캘린더 추가
- **📅 캘린더**: 공연 날짜를 구글 캘린더에 추가해요.
- **⏰ 티켓팅 알림**: 티켓 오픈 시간을 구글 캘린더에 추가해요.
- **📥 .ics 파일**: 전체 공연과 티켓 오픈 일정을 한 번에 내려받아요. 아이폰, 갤럭시, 아웃룩 캘린더에서 쓸 수 있고, **티켓팅 30분 전 알림**이 들어 있어요.

### 그 밖의 기능
- 지난 공연은 자동으로 빼고 날짜순으로 정렬해요.
- 동시 처리 수, 대기열, 입력 길이를 제한해서 API 사용량을 보호해요.
- 사이트 안에서 바로 볼 수 있는 **📖 사용 방법** 안내가 있어요.

## 🛠 기술 스택

- **LLM**: OpenAI `gpt-4o-mini` (Responses API)
- **검색**: OpenAI `web_search_preview` 도구
- **UI**: Gradio (Blocks, Tabs, 커스텀 CSS/테마)
- **캘린더**: Google Calendar 템플릿 링크, iCalendar(.ics) 직접 생성
- **언어**: Python 3.10+

## ⚙️ 동작 방식

```
[공연 검색]  검색어 + 지역/종류          [취향으로 찾기]  좋아하는 아티스트 + 분위기
        │                                        │
        └──────────────┬─────────────────────────┘
                       ▼
        gpt-4o-mini + 웹 검색 (Responses API)
        - 취향 탭: 취향 분석 → 비슷한 아티스트 선정 → 공연 검색 → 추천 이유
        - 공통: 공연 일정 + 선예매/일반예매 오픈 일시를 JSON으로 정리
                       ▼
        파이썬 후처리
        - 날짜 파싱 (2026-12-01 20:00 / 2026년 12월 1일 오후 8시 등)
        - 지난 공연 제거, 날짜순 정렬
        - 티켓팅 D-day 계산 (한국 시간 기준)
        - 구글 캘린더 링크 + .ics 파일 생성
                       ▼
        카드 UI 렌더링 → Gradio 화면
```

날짜 계산과 캘린더 생성은 LLM이 아니라 **파이썬 코드가 직접** 해요. 그래서 D-day가 틀리게 계산되는 일이 없고, 서버가 해외에 있어도 한국 시간 기준으로 맞게 나와요.

## 🚀 실행 방법

### 1. 저장소 받기
```bash
git clone https://github.com/<내-아이디>/gig-radar.git
cd gig-radar
```

### 2. 가상환경 만들고 패키지 설치
```bash
python -m venv venv
# Windows
venv\Scripts\activate
# macOS / Linux
source venv/bin/activate

pip install gradio -r requirements.txt
```

### 3. API 키 설정
프로젝트 폴더에 `.env` 파일을 만들고 OpenAI API 키를 넣으세요.
```
OPENAI_API_KEY=sk-xxxxxxxx
```
> ⚠️ `.env`는 `.gitignore`에 들어 있어서 저장소에 올라가지 않아요. 키를 코드에 직접 적지 마세요.

### 4. 실행
```bash
python app.py
```
브라우저에서 http://127.0.0.1:7860 을 열면 됩니다.

## 📖 사용 방법

1. 위쪽 탭에서 찾는 방법을 골라요.
   - **🔍 공연 검색**: 보고 싶은 가수나 공연을 알고 있을 때
   - **💖 취향으로 찾기**: 좋아하는 아티스트를 바탕으로 새 공연을 추천받고 싶을 때
2. 검색어나 좋아하는 아티스트를 입력하고 버튼을 누르거나 Enter를 눌러요. 결과가 나오기까지 10~30초 정도 걸려요.
3. 결과 카드에서 일정, 티켓팅 D-day, 추천 이유를 확인해요.
4. **📅 캘린더**나 **⏰ 티켓팅 알림**을 눌러 구글 캘린더에 추가하거나, 맨 아래 **.ics 파일**을 받아 휴대폰 캘린더에 한 번에 넣어요.

## ☁️ 배포 (Hugging Face Spaces)

1. Hugging Face에서 **New Space**를 누르고 SDK는 **Gradio**를 골라요.
2. `app.py`와 `requirements.txt`를 업로드해요.
3. **Settings → Variables and secrets**에 `OPENAI_API_KEY`를 **Secret**으로 등록해요.
4. 상태가 Running으로 바뀌면 Space 주소를 공유하면 돼요.

> 💡 다른 사람이 검색할 때마다 내 API 키로 요금이 나가요. OpenAI 대시보드에서 **월 사용 한도**를 꼭 설정하세요.

## ⚠️ 한계와 주의사항

- 결과는 AI가 웹에서 모은 정보라서 **날짜, 티켓 오픈 시간, 장소가 틀리거나 바뀌었을 수 있어요.** 예매하기 전에 공식 예매처 공지를 꼭 확인하세요.
- 티켓 오픈 일정이 아직 발표되지 않은 공연은 D-day가 표시되지 않아요.
- 취향 추천은 AI의 판단이라 사람마다 맞지 않을 수 있어요.
- 검색 한 번마다 OpenAI API 비용(모델 사용료 + 웹 검색 사용료)이 나와요.
